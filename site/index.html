The Pipeline

          
How it Works under the hood

          
Unlike simple one-off scripts, ascii-motion is built like a true terminal media pipeline. Processing is highly vectorized, and rendering avoids full-screen clears.

        

        
        

          

            
01

            
VideoCapture

            
OpenCV captures frames in BGR format and handles high-performance seeking.

          

          
→

          

            
02

            
Vector Processing

            
NumPy resizes and applies luminance/edge filters across full matrices, without slow pixel loops.

          

          
→

          

            
03

            
ASCII Mapping

            
Dithering and LUT (Look-Up Table) operations convert the visual data to character grids instantly.

          

          
→

          

            
04

            
ANSI Render

            
Outputs using cursor-home sequences instead of clearing the screen, eliminating flicker.

          

        

      


      

        

          
Options & Flags

          
Customize your playback

          
Control exactly how the video is processed, colored, and outputted.

        


        

          

            
Visual Modes

            
Switch between standard ASCII, Sobel edge emphasis, or a hybrid blend.

            

              ascii-motion video.mp4 --mode edges
            

          


          

            
ANSI Color

            
Output in truecolor, 256-color, grayscale, or plain text.

            

              --color truecolor
            

          


          

            
Dithering

            
Apply ordered Bayer dithering before mapping.

            

              --dither ordered
            

          


          

            
Interactive Controls

            
Pause, play, and seek using native keyboard events, without a GUI.

Export Workflows

            
Don't just watch it—export frames, text, or full ANSI-encoded animations to replay later.

            

              ascii-motion video.mp4 --export-ansi output.ans --color 256
